## 5 分钟上手

NekoShelf 是单容器私有媒体库：挂上媒体目录（默认只读），它负责索引、封面、阅读与播放。数据库/凭据/备份在 `/config`，缓存可随时清空。

```bash
docker run -d --name nekoshelf -p 8080:8080 \
  -v /你的漫画目录:/data:ro \
  -v /你的配置目录:/config \
  -v /你的缓存目录:/cache \
  -e PUID=1000 -e PGID=1000 -e TZ=Asia/Shanghai \
  nekoshelf:0.5.0
```

1. 打开 `http://NAS地址:8080`，首次跳 `/setup`：设管理员 → 添加媒体库（根路径填**容器内**路径，如 `/data`）。
2. 回设置页点「扫描」；只读扫描，扫完即可浏览。
3. 点开作品阅读，进度自动保存。

也可用 `docker/docker-compose.yml`（改两个卷路径后 `docker compose up -d`）。

## 媒体怎么放

- 一个作品一个目录（散图直放），或一个作品一个压缩包（zip / 7z / rar / cbz）；混合也能归组。
- zip 读中央目录逐页流式输出、不落盘；7z/rar 单页按需解到 `/cache` 后快照缓存。
- 下载中文件不索引：`.pptd`、`.part`、`.downloading`、`.aria2`、`.tmp`、`.!qB`，以及 `.cfg` 伴生配置。
- `thumb.webp` / `cover.jpg` 之类封面文件不算页，会自动挑为封面。

命名识别：

| 形态 | 识别结果 |
| --- | --- |
| `[作者] 标题 [汉化组] [Chinese]` | 标题 / 作者 / 汉化组 |
| `1234567-标题`（E-H 目录） | gid + 标题，跳过推断 |
| `[57P-795MB]` `[463P+67P]` `[108P+7V-1.23GB]` | 页数/视频数声明，用于校验 |
| `001.webp` + `001_CN.webp` | 双语对照，阅读器可切语言 |
| `kcf9.com@DASS-286.mp4` | 剥广告域名 → 番号 DASS-286，同番号合成版本组 |

> 只读是设计原则：扫描、阅读、封面生成都不改媒体目录；只有显式开启「整理」并写回时才动文件。

## 浏览与阅读

- 书库：搜索 300ms 防抖；排序「最近更新/标题/评分」；按库过滤；网格密度与筛选按设备记忆。
- 阅读器：单页 / 双页 / 纵向连续；方向右到左（日漫）或左到右；适配适高/适宽/原始；缩放 1×–2×。
- 每本书记住上次的阅读设置，回落到设置页默认值。
- 快捷键：`←` `→` 翻页、`空格` 下一页、`m` 模式、`p` 方向、`f` 适配、`g` 跳页、`q` 退出。
- 鼠标：滚轮/方向键翻页、悬停出菜单；触摸：点左/右 1/3 翻页、双指缩放、长按不弹菜单。
- 交互模式（自动/触摸/鼠标）可在设置页或阅读器面板手动切换并持久化；移动端按钮不小于 44px。

## 搜索语法

- 多词 AND：`猫 夏天`
- 排除：`-猫`
- 精确短语：`"猫物语"`
- 通配：`猫*`
- 标签：`tag:猫娘`、`tag:group:某某汉化`、`-tag:...`
- 页数：`pages:>100`、`pages:20-80`
- 进度：`read:<50`（百分比）

语法由 `packages/core/src/query.ts` 纯函数解析，不会把用户输入直接拼进 SQL。

## AI 自然语言搜索

用一句话找书（如「页数超过 100 的汉化同人志，排除看过的」）。服务端让大模型把这句话翻译成上面的搜索语法，再走同一个查询引擎；大模型不接触库内容，不做向量检索。

1. 设置页「AI 自然语言搜索」填 DeepSeek API Key（或兼容 OpenAI 的 Base URL + 模型），保存并「测试连接」。
2. 容器需 `ENABLE_LLM_SEARCH=1`，否则功能整体不可用（防误发外网的硬开关）。
3. 结果上方显示「理解成的查询」与标签分布，可一键回普通搜索。

> 会把自然语言描述与标签上下文发给所配置的模型服务商，介意就保持关闭。

## E-H 刮削（里站）

三条硬规则：

1. **默认关闭**：未设 `ENABLE_SCRAPER=1` 时任何页面都不会发外网请求。
2. **已有元数据不重刮**：有 ComicInfo / `.ehviewer` / 已标 E-H 来源则跳过，不覆盖人工字段。
3. **只手动触发**：详情页单条「从 E-H 刮削」，或设置页批量刮削（≤10），无全自动后台任务。

Cookie：设置页填 `ipb_member_id` + `ipb_pass_hash`（必需），`igneous`、`cf_clearance`（可选，里站常需）。浏览器登录里站后从开发者工具 Application → Cookies 复制。凭据 AES-256-GCM 加密存 `/config`，不回显。

请求串行 + 限速（默认 1 req/s，可调 0.2–5），连续失败指数退避；429/509 进冷却。

## 整理与 NFO 写回

「整理」= 按模板重命名/移动媒体，可选写 NFO。默认永远只出预览计划。

模板变量：`{author} {title} {series} {pages} {language} {year} {gid}`，例如 `[{author}] {title} [{language}] {pages}P`。

真正执行要同时满足：容器 `DATA_MODE=writeback` → 设置页打开整理开关 → 执行时带 `confirm`（界面二次确认）。执行写 journal 到 `/config/journal.jsonl`，可在「写回记录」逐条撤销。

「NFO 预览」展示将生成的 Kodi/Jellyfin 兼容 XML；写回同受上述门禁限制。

## 疑似重复与合并

「重复」页按归一化标题分组（去括号/标记/大小写），逐字节相同会高亮。合并 = 被合并项标记隐藏并指向保留项（`merged_into`），**不删文件**；动作可在「写回记录」撤销；有写回动作时需写回门禁。

## 备份与恢复

设置页「备份与维护 → 立即备份」生成 `/config/backups/nekoshelf-<时间>-<版本>.db`（`VACUUM INTO`，一致性快照，可直接拷走）。

恢复（无远程 API，防误操作）：

```bash
docker stop nekoshelf
cd /你的配置目录
cp nekoshelf.db nekoshelf.db.bak-$(date +%s)
rm -f nekoshelf.db-wal nekoshelf.db-shm
cp backups/nekoshelf-<时间>-0.5.0.db nekoshelf.db
chown -R 1000:1000 .
docker start nekoshelf
```

> `nekoshelf.db` 与 `-wal` 必须在本地磁盘卷：SQLite WAL 不支持 SMB/NFS，检测到会拒绝启动。

## 客户端与 API

1. 管理员在设置页生成 API Token（`nks_...`，明文只显示一次），作用域 `read`/`write`/`admin`。
2. 请求头 `Authorization: Bearer nks_...` + `X-API-Version: 1`。
3. 先 `GET /api/meta`；完整契约 `docs/openapi.json` 或运行期 `GET /api/openapi.json`。

浏览器同源用 Cookie 会话即可；跨域 WebView 需配置 `CORS_ORIGINS`。

## 常见问题

**页面 502 / 白屏**：看容器日志；常见是 `/config` 无写权限（PUID/PGID 与目录属主不一致）或 `/data` 路径不存在。

**扫不到文件**：根路径填容器内路径；`.` 开头目录与下载中间态会被跳过；任务页看失败原因。

**封面为空**：页面里没有可作封面的图（或压缩包首页损坏）会显示占位图；重扫可重建，缩略图缓存在 `/cache/thumbs`。

**中文标题乱码**：压缩包内文件名编码不统一（GBK/UTF-8 历史遗留），zip 优先按 UTF-8 标志位读、必要时回退 GBK；仍有问题请提供样本目录名与包名。

**视频不流畅**：默认直连，浏览器不支持才转码；`MAX_TRANSCODE` 限并发，有核显建议 `HWACCEL=qsv`。

**WSL 里容器自己停**：WSL 空闲会回收；开发/演示时保持 `wsl -d Ubuntu -e sleep 3600`。

## 只读保证与合规

默认只读：扫描读目录与包头、阅读按需读图、缩略图写 `/cache`、数据库写 `/config`，不重命名/移动/删除媒体文件；`docker-smoke.sh` 与 `scripts/verify-readonly.ps1` 用扫描前后文件清单对比来验证。

整理/写回是显式开启的例外。请只对你有权处理的内容使用本工具；刮削得到的是第三方站点元数据，注意遵守相应站点条款与当地法律。

## 分类与浏览

书库顶部有「全部 / 漫画 / 图集 / 视频」分类，选择会记住。三个入口：

- **按作者**：作者来自 ComicInfo 的 Writer / Penciller 与目录名前缀，点作者看作品；
- **按系列**：来自 ComicInfo 的 Series 字段，同系列作品自动归组；
- **文件树**：按磁盘真实结构逐级浏览（只读），带作品的条目可直接打开。

作品详情标题下方显示作者 / 画师 / 系列；页面底部有「相关推荐」（同系列、同作者、共享标签）。
归类规则见 `docs/目录特征与归类.md`；判不准的作品可在详情页用 AI 分类。

## 视频播放与缩放

视频作品详情页点「播放视频」进入 `/watch/:id`：Range 直连、不转码；视频包按需解包到 `/cache` 后流式播放。
缩放：`+` / `-` 调整，`0` 复位，`f` 切换「适应窗口 / 原始尺寸」，放大后可拖动查看。
图片阅读器：`Ctrl` + 滚轮缩放，触摸双指捏合，双击切换 1×/2×。

## 标题翻译与 AI 分类

- **翻译标题**：详情页「翻译标题」交给 LLM 翻成中文并保存，列表与详情优先显示中文名；
- **AI 分类**：图集 / 漫画 / 视频判不准时用「AI 判断类型」，模型给出类型与置信度，确认后应用并缓存。

两者都需在「设置 → AI 自然语言搜索」配置 Key 并打开开关（容器 `ENABLE_LLM_SEARCH=1`），默认关闭、不发任何外网请求。
